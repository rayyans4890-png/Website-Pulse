## Website-pulse
This is a website which updates daily and then shows you the top picture from nasa's website. To upload the daily pic it uses an api key which i have mentioned in the git files. I have also added some features of my own in this website beside the tutorial, such as a clock.date and a option to view the image in full detail. This project was made for the stardance challenge Website-Pulse.

# BOM

-Java script 
-Hypertext Markup language(HTML)
-Cascading style sheet(CSS)
-Coder used was VScode
